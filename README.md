# Imaging with Nilearn (2026)

Course materials for the **Imaging with Nilearn** practical session. This repository contains a set of Jupyter notebooks that introduce fMRI data analysis using the [`nilearn`](https://nilearn.github.io/) and [`nibabel`](https://nipy.org/nibabel/) Python packages.

This repository is forked from Dr Yifan Yu's [Nilearn2025 practical repository](https://github.com/yifan0330/Nilearn2025/), with modifications for the 2026 course.

## Getting started

**New to this repository, or don't have Python/Jupyter set up yet? Start with [`SETUP.md`](./SETUP.md).**

It walks through everything needed to get the notebooks running on your own computer (Windows, Mac, or Linux), assuming no prior coding experience.

## What's in this repository

| File / folder | Description |
|---|---|
| `nb_00_introduction.ipynb` | Start here. Course overview and setup check. |
| `nb_01_fmri_data_and_first_level_analysis.ipynb` | fMRI data basics and first-level analysis. |
| `nb_02_second_level_analysis.ipynb` | Second-level analysis and statistical thresholding. |
| `nilearn_data/` | Pre-downloaded example datasets, so the notebooks run without needing to fetch data from the internet during the session. |
| `boxcar.csv` | Example experimental design data used in the notebooks. |
| `Figs/` | Images used in the notebook explanations. |
| `results/` | Example output images generated by the notebooks. |
| `requirements.txt` | The exact Python packages (and versions) needed to run the notebooks. |
| `SETUP.md` | Step-by-step setup instructions for students. |

## Running the notebooks

Once you've completed the setup steps in [`SETUP.md`](./SETUP.md), open the notebooks in the following order:

1. `nb_00_introduction.ipynb`
2. `nb_01_fmri_data_and_first_level_analysis.ipynb`
3. `nb_02_second_level_analysis.ipynb`
